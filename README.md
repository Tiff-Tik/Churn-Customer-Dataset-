# Churn-Customer-Dataset-
The project focuses on analyzing a customer churn dataset to understand customer behaviour, identify factors contributing to customer attrition, and predict customers who are likely to discontinue a service.

Using Python and data analytics techniques, the project explores customer demographics, subscription services, contract types, payment methods, and other relevant customer attributes to uncover patterns associated with churn.

Tools and Technologies
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Jupyter Notebook
- streamlit app
